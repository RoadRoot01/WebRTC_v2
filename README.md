### 실행법 간단 설명

 1. 실행환경: "react": "^19.2.3" / "react-scripts": "5.0.1" / "typescript": "^4.9.5" / Node.js v22.17.1 
 2. env, peer_ts>App.tsx 주소 맞게 변경 HOST= 192.168.0.6 
 3. Terminal 2개 실행 후
    - Server: \webRTC\WebRTC_KAU\Practice_webRTC> npm start
    - Client: \webRTC\WebRTC_KAU\Practice_webRTC\peer_ts> npm start
